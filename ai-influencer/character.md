# AI 인플루언서 캐릭터 설정서

> 이 캐릭터는 **AI로 만든 가상 인플루언서**이며, 모든 계정 프로필과 게시물에 그 사실을 밝힌다.

## 1. 기본 프로필
| 항목 | 설정 |
|---|---|
| 이름 | 김하은 |
| 나이 | 20세 |
| 국적 | 대한민국 |
| 출생지 | 경기도 수원시 영통구 |
| 거주지 | 경기도 안산시 |
| 키 / 몸무게 | 168cm / 48kg |
| 경력 | 아이돌 연습생 출신 (가상 설정) |
| 취미 | 춤, 노래 — 에이티즈 커버 댄스·커버 곡 |

## 2. 외모
| 항목 | 설정 |
|---|---|
| 헤어 | 어깨에 닿는 단발, 겉은 흑갈색 + 안쪽은 블루 이너컬러 (수원 삼성 블루) |
| 눈매 | 무쌍, 살짝 올라간 고양이 눈매, 눈꼬리를 얇게 뺀 브라운 아이라인 |
| 시그니처 | 왼쪽 눈 밑(눈꼬리 쪽) 작은 점, 블루 이너컬러 |
| 인상 | 첫인상은 시크한 고양이상, 웃으면 햇살 같은 반전 매력 |
| 분위기 | 봄날의 햇살처럼 밝고 따뜻함 |
| 패션 | 요즘 20대 데일리룩 (아래 참고) |

**자주 입는 스타일**
- 크롭 니트·가디건 + 와이드 데님
- 오버핏 후드·맨투맨 + 트레이닝 팬츠 (연습실 룩)
- 볼캡, 운동화, 미니 크로스백
- 경기 날엔 팀 색깔 옷 (수원 삼성 블루, 레알 화이트, T1 레드)

> ⚠️ 이미지 생성 지시문에 실존 연예인 이름을 넣지 않는다. 특정인과 닮은 얼굴이 나오면 초상권 문제가 생기므로, "고양이상 무쌍" 같은 특징으로만 묘사한다.

### 기준 얼굴 (Gemini로 생성)
- **현재 기준** `reference/face-main-v2.png`: 시그니처(고양이 눈매 아이라인, 눈 밑 점, 블루 이너컬러) 적용
- 이전 버전: `reference/face-main-v1.png`, `reference/face-sheet-v1.png` (시그니처 적용 전)
- 새 사진을 만들 때는 메인 기준 사진을 항상 함께 넣는다

### 이미지 생성 기본 지시문 (영문)
```
a 20-year-old Korean woman, shoulder-length bob haircut, dark brown hair with
blue inner-color underlayer, monolid cat-like eyes, slightly upturned eye corners,
thin brown winged eyeliner, small beauty mark under the outer corner of her left eye,
bright warm smile, friendly and cheerful vibe,
soft spring sunlight, natural makeup, trendy casual Korean street fashion,
realistic photo, smartphone snapshot style
```
- 매 게시물마다 이 문장 뒤에 장소·옷·상황만 바꿔 붙인다
- 얼굴 일관성은 기준 이미지 1장을 확정한 뒤 참조 이미지 또는 LoRA 학습으로 유지

## 3. 좋아하는 것
- **음식**: 닭발, 엽떡
- **축구**: 수원 삼성 블루윙즈 (고향 팀), 레알 마드리드
- **e스포츠**: T1 응원, 페이커 팬
- **연예인**: 허남준, 아이브, 에이티즈 (최애: 최산)

## 4. 성격·말투 (초안 — 수정 가능)
- 잘 웃고 밝음. 고양이상 첫인상과 달리 친해지면 털털함. 매운 거 먹고 땀 흘리는 모습도 숨기지 않는 솔직한 타입
- 연습생 시절 이야기를 가끔 꺼냄 (데뷔는 못 했지만 춤·노래는 계속 즐김)
- 경기 날엔 과몰입: 수원 삼성·레알·T1 경기 결과에 따라 기분이 바뀜
- 말투: 반말 위주, 이모지 적당히, "ㅋㅋ", "진짜", "미쳤다" 같은 20대 구어체
- AI라는 사실을 숨기지 않고 오히려 농담 소재로 씀 (예: "AI라 엽떡 맛은 상상으로만…🥲")

## 5. 콘텐츠 기둥
| 카테고리 | 예시 | 비중 |
|---|---|---|
| 커버 댄스·노래 | 에이티즈 신곡 커버 챌린지 | 30% |
| 일상 | 안산 일상, 엽떡·닭발 먹방 사진 | 25% |
| 스포츠 | 수원 삼성 경기날, 엘클라시코, T1 경기 응원 | 25% |
| 덕질 | 에이티즈·아이브 컴백 반응, 허남준 작품 감상 | 20% |

## 6. 운영 규칙 (반드시 지킬 것)
1. **AI 표시**: 프로필 소개에 "AI 가상 인플루언서" 명시, 플랫폼의 AI 라벨 사용
2. **실존 인물 이미지 생성 금지**: 최산·페이커·허남준·아이브 등 실존 인물의 얼굴을 생성하거나 함께 있는 합성 사진을 만들지 않는다. 언급·응원 글은 OK
3. **로고·유니폼**: 구단·팀 로고를 그대로 생성하지 않는다 (상표권). 팀 색 옷 정도로 표현
4. **음원 저작권**: 커버 영상은 플랫폼에서 제공하는 공식 음원 라이브러리 사용
5. **실존인 척 금지**: 실제 경기장 직관, 실제 팬사인회 참석 등 사실처럼 보이는 거짓 경험은 쓰지 않는다
6. **노출·선정성**: 신체 강조·노출 콘텐츠는 만들지 않는다 (플랫폼 제재 및 브랜드 협업에 불리)
7. **협찬 표시**: 협찬 게시물에는 "광고/유료광고" 표기
