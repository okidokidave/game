# 인플루언서 시뮬레이터

스마트폰 하나로 방송을 시작해서, 돈을 벌어 장비를 맞추고, 60일 안에 셀럽이 되는 도트 방송 시뮬레이션입니다.
Flutter로 만들었고 안드로이드 출시를 목표로 합니다. (골드 광산 키우기와 같은 방식)

## 1. 게임 규칙

| 요소 | 설명 |
|---|---|
| **방 화면** | 싸이월드 미니룸처럼 벽 두 면과 바닥이 보이는 도트 단면 방. 창밖이 오전·오후·밤에 따라 바뀜 |
| **하루** | 오전·오후·밤 세 번 행동. 밤 방송이 시청자가 가장 많음. 60일이 지나면 시즌 종료 |
| **방송** | 잡담·공부·먹방·노래·게임·리액션·브이로그·ASMR 8가지. 일부는 장비가 있어야 열림. 매주 대세 콘텐츠는 시청자 1.5배 |
| **장비** | 카메라·마이크·조명·PC를 한 단계씩 구입. 산 장비가 방에 그대로 나타남 |
| **꾸미기** | 러그, 화분, 포스터, 네온사인, 빈백, 피규어 진열장, 벽지 색 |
| **기타 행동** | 편집·업로드(PC 필요), 편의점 알바, 휴식, 잠자기 |
| **남녀 캐릭터** | 시작할 때 성별 선택. 여자는 속눈썹·핑크 입술, 남자는 눈썹 |
| **팬 성비** | 여자 방송인은 남자 팬이, 남자 방송인은 여자 팬이 많게 시작. 콘텐츠에 따라 조금씩 바뀜 (게임↑남, 노래·ASMR·브이로그↑여) |
| **성별 SNS 반응** | 글쓴이 성별(♂/♀) 표시, 형/누나/오빠/언니 호칭. 열애설 같은 주제는 이성 팬 반응이 더 격함 |
| **방송 중 말실수** | 방송하면 드물게(7%) 발생. **방송 강행** → 수입·시청자는 줄지만 일부 수입은 남음, 대신 팬 6% 즉시 이탈·안티 생성·논란 / **사과 후 자숙** → 크로마키 앞에서 꾸벅 "죄송합니다", 방송 중단(수입 0) 후 3주 자숙(검은 화면에서 시간이 흐름, 수입 없이 생활비만 나감, 팬은 약 2.5%만 이탈, 논란은 가라앉음) |
| **이사** | 반지하(생활비 7천)에서 시작 → 원룸(구독자 1천·보증금 50만) → 오피스텔(1만·300만) → 아파트(10만·1500만) → 펜트하우스(50만·8000만). 집마다 방 모습·창밖 풍경·생활비가 다르고 시청자 보너스(+5~25%) |
| **방송 중 후원·반응** | 방송 중 후원 팝업("💰 OO님 7,000원 후원!")과 띠링 소리. "💬 반응하기!" 버튼이 두 번 잠깐 뜨고, 누를 때마다 시청자 +8%·구독자 +10%·후원 +15% |
| **SNS 직접 대응** | 가장 최근 트렌드(이틀 안)에 한 번: ✍️ 해명 글(여론이 내 편이면 성공, 아니면 역풍 위험) / ⚖️ 고소(변호사비, 안티 절반·논란 -10) / 📌 팬 댓글 고정(멘탈 +8) / 🤐 무대응. 내 글(✔)과 반응 댓글이 붙고 여론 막대가 움직임 |
| **인기 순위** | 가상 스트리머 9명(구독자 120 ~ 250만)이 매일 밤 함께 성장. 상단 🏆에서 순위표(▲▼ 하루 전 대비), 누군가를 제치면 알림과 SNS 글 |
| **소리** | 8비트 효과음(후원, 반응, 알림, 팡파르)과 배경음악, 진동. 상단 🔊로 끄고 켜기. `python3 tool/generate_sounds.py`로 다시 만듦 |
| **수입·통장** | 매일 밤 생활비(사는 집에 따라 7천~15만 원). 상단 💰를 누르면 날짜별 수입·지출 내역. 통장이 마이너스면 매일 멘탈 -3 |
| **안티** | 많을수록 새 팬이 덜 생기고 SNS 악플이 늘어남. 하루 3%씩 줄어듦 |
| **방송 중 사건** | 악플러, 도네 미션, 뒷광고 제안, 열애설, 정치 질문 등. 선택에 따라 수치가 바뀜 |
| **성장 단계별 사건** | 초반: 대형 스트리머 깜짝 등장, 대형 유튜버 합방 초대 / 3만+: 굿즈 출시 / 10만+: 팬미팅 / 30만+: 예능 출연 / 50만+: 크리에이터 어워즈. 한 판에 한 번씩 |
| **나중에 터지는 일** | 뒷광고·열애 거짓말은 며칠 뒤 아침 뉴스로 폭로될 수 있음 |
| **SNS "버즈"** | 모든 선택이 트렌드가 되어 이슈 글 아래에서 악플과 쉴드가 맞붙음. 쉴드 vs 비난 여론 막대 |
| **마일스톤** | 구독자 100 / 1천(수익화) / 1만(실버 버튼) / 10만(골드) / 100만(다이아). 버튼은 방 선반에 올라감 |
| **게임 오버** | 논란 100 → 자숙 엔딩, 멘탈 0 → 번아웃 엔딩 |
| **엔딩** | 8가지. 엔딩 도감은 시작 화면에 표시 |

## 2. 폴더 구조

```
influencer_sim/
├── lib/
│   ├── main.dart                 앱 시작점, 시작 화면 ↔ 게임 화면
│   ├── game/                     ← 게임 규칙 (화면과 분리, 테스트 가능)
│   │   ├── data.dart             장비, 방송 종류, 이벤트, SNS 문구, 엔딩 (내용 추가는 여기서)
│   │   ├── rules.dart            시청자·구독자·수익 계산 (밸런스 조절은 여기서)
│   │   ├── sns.dart              SNS 글·댓글 토론 만들기
│   │   ├── game_state.dart       저장되는 데이터
│   │   ├── game_controller.dart  방송, 이벤트, 하루 진행, 상점, 엔딩
│   │   └── save_repository.dart  기기에 저장/불러오기
│   ├── scene/                    ← 움직이는 도트 방
│   │   ├── room_painter.dart     방, 가구, 장비, 캐릭터 그리기
│   │   └── room_view.dart        애니메이션 (캐릭터, 하트, 채팅 풍선)
│   ├── ui/                       ← 화면
│   │   ├── title_screen.dart     시작 화면 (닉네임, 머리·옷 색)
│   │   ├── home_screen.dart      게임 화면 (상태판, 방, 행동 버튼, 기록)
│   │   ├── sns_phone.dart        SNS "버즈" 휴대폰 화면
│   │   ├── dialogs.dart          사건·결과·콘텐츠·상점 팝업
│   │   └── palette.dart          색, 공용 버튼 (그라데이션 버튼, 카드, 알약 표시)
│   ├── audio/                    효과음·배경음악·진동 (골드 광산과 같은 방식)
│   └── ads/                      광고 (AdMob, 골드 광산과 같은 코드)
├── assets/sounds/               효과음·배경음악 WAV (tool/generate_sounds.py 로 생성)
├── assets/fonts/                프리텐다드 글꼴 (SIL Open Font License, LICENSE.txt 동봉)
├── test/                         자동 테스트 (밸런스, 규칙, SNS, 60일 끝까지 플레이)
├── tool/                         아이콘 생성, 가상 폰 실행 확인 스크립트
└── android/                      안드로이드 빌드 설정
```

### 이벤트 추가하기
`lib/game/data.dart`의 `gameEvents`에 `GameEvent`를 하나 넣으면 됩니다. 선택지마다 `fx`(수치 변화)와
`sns`(태그, 기사 제목, `tone`: -1 악플 위주 ~ 1 쉴드 위주, 진영별 문구)를 적습니다.

## 3. PC 없이 휴대폰만으로 개발하기

골드 광산 키우기와 똑같습니다. APK 빌드는 GitHub 서버가 대신 해요.

```
휴대폰에서 Claude와 대화 → 코드 수정 & GitHub에 push
      → GitHub Actions가 자동으로 검사·테스트·APK 빌드·가상 폰 실행 확인 (약 10분)
      → 휴대폰에서 고정 주소로 APK 내려받아 설치
```

**APK 다운로드 주소 (항상 최신 빌드):**
https://github.com/okidokidave/game/releases/download/influencer-build/influencer-sim.apk

(골드 광산 APK 주소와 따로라서 서로 덮어쓰지 않아요.)

### 처음 설치할 때
1. 휴대폰 브라우저에서 위 주소를 엽니다 → `influencer-sim.apk`가 내려받아집니다.
2. 알림창이나 "내 파일 → 다운로드"에서 파일을 누릅니다.
3. "출처를 알 수 없는 앱 설치" 경고가 뜨면 **설정 → 이 출처 허용**을 켜고 **설치**를 누릅니다.
4. Play 프로텍트 경고가 뜨면 **세부정보 → 무시하고 설치**를 누릅니다.

### 업데이트할 때
같은 주소에서 새 APK를 받아 설치하면 덮어 설치되고, 게임 저장 데이터는 그대로 유지됩니다.

### 빌드 상태 확인
https://github.com/okidokidave/game/actions 에서 "인플루언서 시뮬레이터 APK 빌드"를 봅니다.
실패하면 Claude에게 "빌드 실패했어"라고 말하면 됩니다.

## 4. 출시 준비

서명 키, AdMob 실제 광고 ID, 원스토어·Google Play 등록 절차는 골드 광산 README(`gold_mine/README.md`, 5~7장)와 같습니다.
이 앱에서 바꿀 곳:

| 항목 | 위치 |
|---|---|
| 앱 ID (출시 후 변경 불가) | `android/app/build.gradle.kts` → `com.okidokidave.influencer_sim` |
| AdMob 앱 ID | `android/app/src/main/AndroidManifest.xml` |
| 광고 단위 ID | `lib/ads/ad_ids.dart` (지금은 화면 아래 배너만 사용, 테스트 광고) |
| 앱 아이콘 | `python3 tool/generate_icon.py` (스토어용 512px: `assets/icon/store_icon_512.png`) |
| 버전 | `pubspec.yaml`의 `version` |

출시용 키를 Secrets에 넣는 방법도 골드 광산과 같습니다 (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`).
