# 《혈화》 비슷한 이름 정리안

## 1. 문제: 겹치는 글자

| 겹치는 글자 | 이름 |
|---|---|
| **천** | 소천, 천휘, 천윤, 백무천, 위진천, 노천복, 천무극, 천극문, 천의단, 흡천신공 |
| **무** | 태무진, 백무천, 진무혁(무영), 천무극, 염무극, 무애검 |
| **진** | 태무진, 진무혁, 위진천, 도진백 |
| **극** | 천극문, 천무극, 염무극 |
| **백** | 백무천, 도진백 |
| **운** | 소운, 적운 |

가장 위험한 짝
- **태무진 ↔ 진무혁**: 같은 글자(무·진)를 뒤집어 놓은 꼴이다. 한쪽은 아이들을 지킨 스승, 한쪽은 최종 보스라 혼동하면 치명적이다.
- **천극문 ↔ 천무극**: 문파 이름과 그 문파 수장의 이름이 거의 같다.
- **천극문 ↔ 천의단**: 둘 다 "천○○" 형태의 큰 세력이다.
- **염무극 ↔ 천무극**: 끝 두 글자가 같다.

## 2. 원칙
1. **이야기의 중심 이름은 지킨다**: 소운, 소천, 월영, 천휘, 진무혁, 백무천, 서련화, 구만석, 한도겸.
2. **가족은 일부러 글자를 나눈다**: 소운·소천(소), 천휘·천윤(천)은 형제라서 겹쳐도 된다. 오히려 "이 둘은 가족"이라는 신호가 된다. 진무혁과 그 동생(본파 수장)도 같은 방식으로 묶는다.
3. **나머지 이름에서는 천·무·진·극·백·운을 빼고**, 인물의 인상이 이름에서 느껴지게 짓는다.

## 3. 바꾸는 이름 (제안)

### 꼭 바꿀 것
| 지금 | 바꿀 이름 | 이유와 뜻 |
|---|---|---|
| 태무진(太武眞) | **태하원(太河源)** | 진무혁과 뒤집힌 이름 해소. 큰 강의 근원. 말없이 흘러가며 사람을 살리는 방랑 검객 |
| 염무극(廉武極) | **염세경(廉世卿)** | 진무혁·백무천과 "무" 겹침 해소. 세상의 도리를 따지는 선비 같은 인상, 결단하지 못하는 온건파 |

### 바꾸는 것을 권하는 것
| 지금 | 바꿀 이름 | 이유와 뜻 |
|---|---|---|
| 천극문(天極門) | **건곤문(乾坤門)** | "천○○" 세력이 셋이라 하나를 뺀다. 하늘과 땅, 강호의 질서를 지키던 정통 대문파라는 뜻이 그대로 산다. "천극문계"는 "건곤문계"가 된다 |
| 위진천(魏震天) | **위학송(魏鶴松)** | 학과 소나무. 백발, 격식, 오래 버틴 권력자의 인상 |
| 도진백(都震白) | **도강필(都剛弼)** | 굳셀 강, 도울 필. 호위대 출신, 원칙과 동료애 |

### 선택 (바꿔도 되고 그대로 둬도 됨)
| 지금 | 바꿀 이름 | 이유와 뜻 |
|---|---|---|
| 노천복(盧天福) | **노대길(盧大吉)** | "천" 하나를 더 뺀다. 능청스러운 장사꾼 같은 인상 |
| 적운(赤雲) | **적상(赤霜)** | 주인공 소운과 "운"이 겹친다. 붉은 서리, 상처투성이 외눈 노장 |

## 4. 바꾼 뒤의 모습

| 글자 | 남는 이름 |
|---|---|
| 천 | 소천, 천휘, 천윤 (가족) / 백무천 / 천의단 / 흡천신공 (무공 이름) |
| 무 | 백무천, 진무혁(무영), 무애검 |
| 진 | 진무혁 (동생 이름은 미정) |
| 극 | 없음 |
| 백 | 백무천 |
| 운 | 소운 |

## 4-1. 천무극에 대하여
"천무극"은 처음 올린 정리본(A본)에만 두 번 나온다 ("진무혁이 조종하는 천무극", "천무극을 조종"). 누구인지 설명은 없다. 작가는 진무혁의 동생이 있지만 이름이 천무극은 아니라고 기억한다. 예전 정리 과정에서 "천극문"과 "진무혁"이 섞여 생긴 이름일 가능성이 있다. → 쓰지 않는다. 진무혁 동생의 이름은 작가의 기억을 기다린다.

## 5. 그대로 두는 이름
소운(昭雲), 소천(昭天), 월영(月影), 천휘(天輝), 천윤(天潤), 백무천(白無天), 서련화(徐蓮花), 진무혁(秦武赫, 무영 無影), 구만석(具萬碩), 사공철(司空哲), 한도겸, 주만복, 현월세가(玄月世家), 천의단(天義團), 청화궁(靑花宮), 망혼곡(亡魂谷), 흡천신공(吸天神功), 무애검(無碍劍)

※ 한도겸·주만복은 아직 한자가 정해지지 않았다.
